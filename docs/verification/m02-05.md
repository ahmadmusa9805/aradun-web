## Implemented operational contract

- `registeredModels` is maintenance-only and returns AuditEvent on an explicit connection without opening it. Index metadata is derived from that schema; no parallel hand-maintained index list or eager app registry import.
- `expectedIndexes` works offline; `checkIndexes` performs bounded listIndexes, reports missing/drift/extra and fingerprints database plus observed differences. A missing namespace is reported without creating it. Same-name option drift is a failure, not an implicit repair.
- `applyIndexPlan` rechecks the exact fingerprint, refuses drift/extras, preflights all missing unique indexes before DDL, adds missing indexes and verifies. Duplicate values are not returned. Server unique enforcement still handles races after preflight. No drop/sync/reset/update/migration side effects. Preflight supports current ordinary numeric-direction, non-sparse/default-collation registry; unsupported unique options fail for explicit adapter review instead of guessing. No production-scale load/capacity claim.
- CLI `npm run db:indexes -- --plan` is offline. `--check` is read-only and requires separate backend DB_OPERATIONS_URI/.env.operations, never fallback to MONGODB_URI. Connection pool is one with finite selection/connect/socket/queue waits and closes on completion. Error output excludes URI, credentials, data and evidence contents.
- `--apply reviewed-evidence.json` is development-only and requires matching database, current fingerprint, reviewed=true, nonempty backupReference and recoveryVerified=true. These attestations reference operator evidence; they cannot prove environment ownership or perform a restore. Staging/production apply is refused before connecting. No owner database CLI apply was executed. Tests call the internal helper only on verified disposable MongoDB.
- DDL is not transactionally atomic across indexes/collections. Failure requires inspection and a newly reviewed plan; no automatic destructive rollback. Production operator identities, credential separation, real backup/restore evidence and release authorization remain unprovisioned gates, not implied readiness.
